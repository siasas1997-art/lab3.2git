# Git-Branches-LPR

## Описание проекта
Данный репозиторий создан для выполнения лабораторной работы по изучению Git и работе с ветками (branches).

В проекте используются три основных типа веток:
- main — стабильная версия проекта;
- develop — ветка интеграции;
- feature — ветки для разработки отдельных функций.

## Настройка разработки
Для работы с проектом необходимо установить:
- Git
- Visual Studio Code

Команды для начала работы:

```bash
git clone <repository-url>
git switch develop
```

## Дополнительная документация
Работа выполняется в соответствии с инструкцией по Git Branching Workflow и правилами оформления commit messages.
